Software Developer with 4+ years of experience building and delivering production-grade web and mobile applications.

I have a strong background in React, TypeScript, React Native, and frontend architecture, alongside hands-on experience with Python, FastAPI, REST APIs, PostgreSQL, Docker, CI/CD, deployment, and production support.

I am particularly interested in aerospace, manufacturing, connected systems, telemetry, AI-powered applications, and mission-critical software.
